# Sistema de Gerenciamento (Clientes, Produtos e Pedidos)

## Tecnologias

* Java
* Spring Boot
* JPA / Hibernate

## Como executar

1. Clonar o repositório
2. Mudar a senha na "application.properties" para a senha do seu banco de dados local
3. Rodar a aplicação
4. Acessar endpoints via Postman

## Endpoints principais

* /api/clientes
* /api/produtos
* /api/pedidos
